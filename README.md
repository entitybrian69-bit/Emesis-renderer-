# Emesis Renderer

A high-performance Minecraft: Java Edition renderer targeted at Android launchers.

## Goals

- Maximize FPS and frame times on mobile SoCs
- Lightweight, low-overhead rendering path
- Compatible with common Android Minecraft launchers (e.g. Aerix, Pojav-based)
- Support for modern and legacy Minecraft versions

## Status

Early development. Core renderer implementation is not yet public.
